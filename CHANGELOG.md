# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-18

### Добавлено

- **Локальные профили**: несколько независимых библиотек на одном компьютере. У каждого
  профиля свои треки, плейлисты, избранное, тексты, обложки и офлайн-загрузки — целиком в
  каталоге `userData/profiles/<id>/`. Переключение, создание, переименование и удаление в
  настройках; единственный профиль удалить нельзя. Это не аккаунты: ни входа, ни сети.
- **Импорт списка треков** из другого сервиса: вставьте строки «Исполнитель — Название» или
  откройте `.txt`, `.csv` (в том числе с заголовком в любом порядке колонок), `.tsv`,
  `.m3u`/`.m3u8`. Строки дедуплицируются, предпросмотр показывается до запуска.
- **Сопоставление** каждой строки: сначала с собственной библиотекой, затем (по желанию) с
  открытым архивом Internet Archive, затем с LRCLIB для текстов. Результат сохраняется
  плейлистом с отчётом: найдено локально / в архиве / без звука / текстов сохранено.
- **Экспорт плейлиста** в M3U8, CSV или JSON. Ссылки на звук не выгружаются никогда; в M3U8
  попадают только пути к вашим локальным файлам, а строки без файла сохраняются
  комментариями, чтобы чужие плееры их просто пропускали.
- Пункт меню «Импортировать список треков…» (`Ctrl+Shift+L`).
- Юнит-проверки `npm run test:tracklist` (33 проверки) для разбора списков и экспорта,
  подключённые в CI.

### Изменено

- **Схема хранения**: документ `kolaars.json` переехал в каталог профиля. Каталог данных от
  версии 1.0.0 переносится в профиль «Основной» при первом запуске — существующая библиотека
  сохраняется. Реестр профилей — `profiles.json` в корне каталога данных.
- Трек без звуковой ссылки теперь сообщает об этом понятнее: «У этого трека нет звука —
  сохранены только название и текст».

### Документация

- README: разделы про профили, импорт/экспорт списков и **явное описание того, чего
  приложение не делает** — оно не обращается к Яндекс.Музыке, Spotify и Genius: их правила
  запрещают автоматический доступ, а тексты песен охраняются авторским правом. Для
  защищённой музыки свободного источника звука не существует, поэтому такая строка
  сохраняется как название и текст без аудио.

## [1.0.0] — 2026-10-18

Первый публичный выпуск.

### Добавлено

- **Обзор** с десятью подборками открытой музыки из Internet Archive (Great 78 Project,
  Musopen, Netlabels): подборки показываются мгновенно из встроенного каталога, затем
  дополняются свежими результатами поиска.
- **Поиск** по Internet Archive с постраничным выводом, ограничением по коллекции и
  сортировкой по популярности.
- **Библиотека** с импортом файлов и папок, чтением тегов и обложек через `music-metadata`.
- **Избранное, плейлисты и очередь** воспроизведения, режимы перемешивания и повтора.
- **Загрузки** для офлайн-прослушивания со страницы загрузок.
- **Тексты песен**: встроенный сборник из 65 песен общественного достояния, синхронизация
  LRC, онлайн-поиск через LRCLIB и Wikisource по явному действию пользователя.
- **Мастерская текстов**: ручная правка, синхронизация по клику, импорт и экспорт `.lrc`.
- **Интерфейс**: тёмная и светлая темы, настраиваемый акцент, полноэкранный режим «Сейчас
  играет», панели текста и очереди, справочник клавиатурных сокращений, поддержка
  медиа-клавиш Windows.
- **Безопасность**: изолированный рендерер (`contextIsolation`, `sandbox`), привилегированная
  схема `kmedia://` со списком разрешённых путей, строгий CSP, открытие внешних ссылок в
  системном браузере.
- **Хранение**: единый документ `kolaars.json` с атомарной записью и debounce, восстановление
  после повреждения файла.
- **Инструменты разработчика**: генератор иконок, сборщик встроенного каталога, подготовка
  офлайн-кэша `electron-builder`, smoke-тест интерфейса по протоколу Chrome DevTools и
  отдельный smoke-тест собранного приложения (`npm run smoke:packaged`), который проверяет
  загрузку из `app.asar`, чтение тегов и воспроизведение локального файла через `kmedia://`.
