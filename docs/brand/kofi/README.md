# Аватарка для Ko-fi

Аватарки Kolaars Music для Ko-fi. Основной вариант — «Волна» в градиенте
тёмный серо-зелёный → голубой.

| Файл | Вариант | Когда подходит |
| --- | --- | --- |
| `png/avatar-wave-1024.png` | Волна | **Выбранный вариант.** Читается даже в 48 px, волна совпадает с иконкой приложения. |
| `png/avatar-monogram-1024.png` | Монограмма | Альтернатива для личного профиля: буква K + фирменный фиолетово-синий градиент. |
| `png/avatar-vinyl-1024.png` | Пластинка | Альтернатива в спокойном «музыкальном» стиле. |

## Что загружать

Для Ko-fi достаточно квадратного PNG: `*-1024.png` (запас качества) или `*-400.png`
(минимальный рекомендуемый размер). Ko-fi показывает аватарку кругом — все макеты
собраны с учётом круглой обрезки.

`preview.png` — как варианты выглядят в круге на 340, 96 и 56 px.

## Исходники

`avatar-*.svg` — векторные исходники 1024×1024.

- «Волна»: `#343E39` → `#2F6D8A` → `#5BC0EB`
- «Монограмма» и «Пластинка»: `#8B5CFF` → `#4A7CFF` → `#2EC8FF`
- Фон: `#08080D`

Белые полосы волны не меняются, поэтому градиент можно править прямо в SVG —
замените три `stop` в `linearGradient id="v2-bg"`.
