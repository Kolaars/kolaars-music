# Тексты песен

Kolaars Music работает только с открытыми текстами. Порядок разрешения намеренно простой и
предсказуемый, а сеть используется только тогда, когда пользователь сам об этом попросил.

## Порядок разрешения

1. **Сохранённый текст** — то, что уже лежит в `kolaars.json` (пользователь правил его сам,
   загрузил из `.lrc` или сохранил результат поиска).
2. **Встроенный сборник** — `data/lyrics-pack.json`, 65 песен общественного достояния.
   Работает офлайн и показывается сразу, ещё до любого онлайн-поиска.
3. **Ничего** — если текста нет, панель предлагает найти его онлайн.

Онлайн-провайдеры (**LRCLIB** и **Wikisource**) опрашиваются **только по явному действию**
пользователя в панели текста или в мастерской. Автоматического «догружания» текстов при
воспроизведении нет.

## Встроенный сборник (`src/main/lyrics/pack.ts`)

Сборник собирается из `data/lyrics-pack.json`:

```json
{
  "name": "Kolaars Public-Domain Lyrics Pack",
  "version": "1.0.0",
  "license": "Public domain — published before 1931, no rights reserved",
  "note": "…",
  "songs": [
    {
      "id": "danny-boy",
      "title": "Danny Boy",
      "aliases": ["Londonderry Air"],
      "artist": "Frederic Weatherly",
      "year": 1913,
      "language": "en",
      "lyrics": ["Oh Danny boy, the pipes, the pipes are calling", "…"]
    }
  ]
}
```

Поиск терпим к «грязным» названиям в Internet Archive («DANNY BOY - ART TATUM - Tatum»,
«St. Louis Blues (Take 2)»), поэтому сопоставление идёт в несколько шагов:

1. **Нормализация** (`normalizeTitle`): нижний регистр, снятие диакритики (`Noël` → `noel`),
   замена `&` на `and`, удаление скобочных уточнений и хвоста «— исполнитель — композитор»,
   удаление слов вроде `remaster / take 2 / mono / instrumental`, отбрасывание ведущего `the`.
2. **Точное совпадение** нормализованного названия с названием или псевдонимом.
3. **Вхождение** самого длинного названия из сборника в название трека по границам слов
   (не короче 8 символов, чтобы короткие названия не совпадали со всем подряд).
4. То же самое, но уже по строке «исполнитель + название».

Кандидаты дополнительно ранжируются по совпадению исполнителя (`pickBest`).

`searchBundledSongs(query)` используется в мастерской: он ищет по названию, псевдонимам,
исполнителю и началу текста, возвращая обычные `LyricsCandidate` с оценкой.

## LRC

Единственная реализация формата — `src/shared/lrc.ts`, общая для главного процесса и
интерфейса:

| Функция | Назначение |
| --- | --- |
| `parseLrc(text)` | Разбор LRC: теги `[ti:]`, `[ar:]`, `[al:]`, `[offset:]`, строки и слова с временем. Возвращает синхронизированные строки и «плоский» текст. |
| `serializeLrc(synced, meta)` | Обратная сборка `.lrc` для экспорта. |
| `formatTimestamp(seconds)` | `mm:ss.xx` для отображения. |
| `parseTimestampInput(input)` | Разбор времени, введённого руками в мастерской. |
| `distributeTimings(plain, duration, leadIn)` | Черновая раскладка строк по длительности трека. |
| `emptyLyrics(trackId)` | Пустой документ для новой правки. |

Поскольку модуль общий, тайминги, показанные в панели текста, и тайминги, записанные в файл,
считаются одинаково.

## Онлайн-провайдеры (`src/main/providers/lyrics.ts`)

### LRCLIB (`https://lrclib.net/api`)

Открытая база текстов от сообщества, умеет отдавать **синхронизированные** тексты.

- `lrclibGet(artist, title, duration)` — точный запрос `/get`; промах не считается ошибкой.
- `lrclibSearch(artist, title, duration)` — нечёткий поиск `/search`, до 12 результатов,
  дедупликация по «название + исполнитель + длительность».
- Оценка кандидата (`score`): синхронизированный текст важнее плоского, совпадение
  длительности даёт до +40, явное расхождение — штраф.
- Инструментальные записи (`instrumental`) отбрасываются.

### Wikisource (`https://en.wikisource.org/w/api.php`)

Проверенные тексты в общественном достоянии.

1. поиск страниц по названию;
2. получение вики-текста через `action=parse`;
3. очистка HTML в простой текст (`stripHtml`) с сохранением переносов строк;
4. результат возвращается как кандидат без синхронизации, с пометкой источника.

Пользователь всегда видит, откуда пришёл текст, и решает, сохранять ли его.

## Мастерская текстов

Экран для работы с текстами поверх текущего трека:

- **Поиск** по встроенному сборнику и онлайн-источникам с показом оценки и источника.
- **Сравнение кандидатов**: выбор одного из нескольких вариантов.
- **Ручная правка** плоского текста.
- **Синхронизация по клику**: включите воспроизведение и щёлкайте по строкам — время
  записывается в текущую позицию трека.
- **Черновая раскладка**: `lyricsDraftTimings` равномерно распределяет строки по длительности.
- **Импорт и экспорт `.lrc`** через системные диалоги.

## Настройки

- `onlineProviders` — общий выключатель онлайн-обращений.
- `providers.lrclib`, `providers.wikisource` — отдельные флаги.

Если провайдер выключен, соответствующий запрос не выполняется вовсе, а не просто скрывается
из интерфейса.
