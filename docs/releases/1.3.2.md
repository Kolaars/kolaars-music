## Kolaars Music 1.3.2 — Discord Rich Presence и проверка встраивания YouTube

Главное: текущий трек теперь можно показывать в профиле Discord — с обложкой, таймером
и кнопками. Второе заметное изменение касается YouTube: приложение спрашивает у
официального API, разрешил ли автор встраивание, и не пытается запускать запрещённое видео.

### Добавлено

- **Discord Rich Presence.** В настройках появился необязательный переключатель. Показываются
  название трека, исполнитель, альбом, состояние «играет» / «пауза», прошедшее время и
  обложка. Активность отправляется с типом `Listening`, поэтому Discord пишет «Слушает
  Kolaars music», как музыкальные сервисы. Официальный Application ID уже встроен: включать
  функцию можно без создания собственного приложения Discord. Поле в настройках нужно только
  для форков и отдельных сборок. Подробности —
  [docs/discord-rpc.md](https://github.com/Kolaars/kolaars-music/blob/master/docs/discord-rpc.md).
- **Кнопки в активности.** Discord разрешает не больше двух, поэтому они зависят от трека:
  - Internet Archive и встроенный открытый каталог — **«Скачать»** (прямой публичный файл)
    и **«Источник»** (страница записи);
  - YouTube Music — **«Открыть в YouTube Music»** и **«Скачать Kolaars Music»**;
  - SoundCloud — **«Открыть в SoundCloud»** и **«Скачать Kolaars Music»**;
  - локальный файл — **«Найти в YouTube Music»** (публичный поиск по исполнителю и названию)
    и **«Скачать Kolaars Music»**.
- **Проверка `status.embeddable`.** Поиск YouTube запрашивает у официального API разрешение
  на встраивание. Если автор его запретил, строка помечается, не запускает плеер и предлагает
  «Открыть в YouTube Music».

### Исправлено

- **Отказ официального плеера во время воспроизведения.** Если API разрешил встраивание, а
  плеер всё равно отказал (возрастной фильтр, лицензия, регион, коды 101/150), приложение
  запоминает это и показывает ту же кнопку. «Играть всё» пропускает такие видео и запускает
  следующий доступный трек.
- **Карточка YouTube-плеера была ниже допустимого размера.** При ширине 320 px область видео
  получалась 320 × 180 px, а официальный плеер требует не меньше 200 × 200 px. Теперь высота
  области — 200 px.

### Важно знать

- **Кнопки Discord видит не автор активности.** Клиент не показывает их в собственном
  профиле — это ограничение Discord, а не приложения. Проверить можно со второго аккаунта,
  наведя курсор на себя в голосовом канале, или попросив друга открыть профиль.
- **Локальная обложка в Discord не отправляется.** Discord умеет загружать картинку только по
  публичному https-адресу, поэтому у локального файла остаётся заглушка. Запасную картинку
  можно задать, загрузив иконку приложения в Developer Portal.
- **«Скачать» — только для открытых записей.** У YouTube Music и SoundCloud звук идёт из
  официального плеера сервиса; ссылки на скачивание для них приложение не создаёт.

### Установка

- `kolaars-music-1.3.2-setup.exe` — установщик для Windows 10/11 x64;
- `kolaars-music-1.3.2-portable.exe` — портативная версия.

Никаких аккаунтов и регистрации: библиотека, история и плейлисты хранятся локально.
