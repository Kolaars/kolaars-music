## Kolaars Music 1.3.4 — обновления прямо из приложения

Главное: больше не нужно проверять GitHub или Telegram в надежде на новую версию. Приложение
само узнаёт о выпуске и устанавливает его — с проверкой контрольной суммы и перезапуском.

### Добавлено

- **Автоматическая проверка обновлений.** Через 20 секунд после запуска и затем каждые
  6 часов приложение спрашивает GitHub Releases о новой версии. Если выпуск новее, внизу
  окна появляется плашка с номером версии и кнопкой «Скачать»; при неактивном окне
  показывается системное уведомление.
- **Установка без похода на сайт.** Установщик Windows скачивает обновление внутри
  приложения, проверяет SHA-512 из `latest.yml` и после нажатия «Перезапустить и обновить»
  заменяет файлы и открывает новую версию. Библиотека, плейлисты и настройки остаются на
  месте.
- **Полный контроль в настройках.** «Настройки» → «Обновления»: текущая версия, состояние
  проверки, прогресс загрузки, кнопки «Проверить обновления», «Скачать обновление» и
  «Перезапустить и обновить». Там же — переключатель «Автоматическая проверка» (включён по
  умолчанию).
- **Пункт в меню.** «Справка» → «Проверить обновления…» запускает ручную проверку и
  открывает настройки обновлений.
- **Портативная и dev-сборка.** Они не могут заменить свой исполняемый файл, поэтому
  проверяют последний выпуск через публичный GitHub API и открывают страницу релиза с
  новым файлом.

### Важно знать

- **Автоматически обновляется установленная версия для Windows.** Портативный `.exe`
  нужно скачать заново со страницы релиза — данные в папке профиля при этом не трогаются.
- **Проверку можно отключить.** Переключатель в настройках убирает фоновые проверки;
  ручная проверка и пункт меню продолжают работать. Для полного отключения (например, в
  автоматизированных запусках) есть переменная `KOLAARS_DISABLE_UPDATE_CHECK=1`.
- **Это не телеметрия.** Запрос к GitHub не содержит идентификаторов, содержимого
  библиотеки или истории прослушивания. Данные о вас никуда не отправляются.
- **Проверка требует интернета.** Офлайн-режим, воспроизведение и остальные функции
  работают как раньше; при недоступной сети фоновая проверка молча пропускается.

### Установка

- `kolaars-music-1.3.4-setup.exe` — установщик для Windows 10/11 x64;
- `kolaars-music-1.3.4-portable.exe` — портативная версия.

Установленные версии 1.3.4 и новее обновляются сами. Пользователям 1.3.3 и более ранних
достаточно один раз скачать установщик 1.3.4 — дальше обновления придут внутри приложения.

Никаких аккаунтов и регистрации: библиотека, история и плейлисты хранятся локально.

Полный список изменений — в [CHANGELOG.md](https://github.com/Kolaars/kolaars-music/blob/master/CHANGELOG.md).

Новости, анонсы выпусков и обсуждение — в [Telegram-канале](https://t.me/kolaars_music).
