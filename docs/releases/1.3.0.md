## Kolaars Music 1.3.0 — YouTube Music и SoundCloud

Главное: в приложении появился экран **«Источники»**. Подключите свой ключ YouTube Data API v3
и SoundCloud `client_id`, найдите трек и слушайте его в официальном встроенном плеере сервиса.
Это не загрузчик и не обход DRM: звук идёт из плеера самого сервиса, а ключи хранятся
зашифрованными и не возвращаются в интерфейс.

### Добавлено

- **YouTube Music.** Поиск через официальный YouTube Data API v3, воспроизведение через
  официальный YouTube IFrame Player. Работают очередь, повтор, перемотка, громкость,
  избранное и плейлисты.
- **SoundCloud.** Поиск через официальный публичный API, воспроизведение через официальный
  SoundCloud Widget. Треки, которые автор запретил встраивать, отфильтровываются при поиске.
- **Экран «Источники».** Ввод и проверка ключей, включение и выключение источников,
  постраничный поиск и кнопка «Играть всё». Подробная инструкция —
  [docs/sources.md](https://github.com/Kolaars/kolaars-music/blob/master/docs/sources.md).
- **Внешние треки в общей библиотеке.** Повтор, перемотка, громкость, избранное и плейлисты
  работают как с обычными записями. Внешний трек сохраняется в библиотеке только когда вы
  добавляете его в избранное или плейлист, — тогда ссылка переживает перезапуск.
- **Зашифрованные ключи.** `safeStorage` (DPAPI в Windows, Keychain в macOS, libsecret в
  Linux) хранит ключи отдельно от библиотеки. В рендерер уходит только состояние «ключ
  сохранён», а параметры `key` и `client_id` вырезаются из текстов ошибок.

### Исправлено

- **YouTube-плеер падал с ошибкой 153.** Официальный IFrame Player отклоняет страницы с
  `file://`-origin: запрос приходит без HTTP-referrer. Собранный интерфейс теперь отдаётся
  встроенным HTTP-сервером только на `127.0.0.1` (порты 41723–41727), поэтому у страницы есть
  обычный origin и referrer. Сервер отдаёт лишь файлы приложения и не выходит за пределы
  компьютера.
- **Медленное восстановление сессии могло перехватить уже выбранный трек.** Теперь
  восстановление проверяет, что текущий трек всё ещё тот же, и отменяется при смене.
- **Позиция и караоке замирали, когда окно перекрыто другим приложением.** Позицию
  дополнительно синхронизирует `timeupdate` самого аудиоэлемента, а рендерер не уходит в
  фоновый режим при перекрытии окна.
- **Меню внешнего трека** больше не предлагает скачать файл или перейти к альбому архива —
  у внешней записи нет ни файла, ни альбома.

### Важно знать

- Для YouTube Music нужен **свой ключ YouTube Data API v3**, для SoundCloud — **свой
  `client_id`**. Без ключа источник не ищет; сами официальные плееры работают независимо.
- **Полный стрим доступен только для YouTube Music и SoundCloud.** Яндекс.Музыка не
  предоставляет публичного API для сторонних плееров; Spotify требует Premium, Web Playback
  SDK и Widevine (в стандартном Electron его нет); Deezer отдаёт через публичный API только
  30-секундные превью. Приложение не обходит эти ограничения через внутренние API, перехват
  токенов или расшифровку DRM.
- Квота YouTube Data API по умолчанию — около 100 поисков в день на проект.

### Установка

- `kolaars-music-1.3.0-setup.exe` — установщик для Windows 10/11 x64;
- `kolaars-music-1.3.0-portable.exe` — портативная версия.

Никаких аккаунтов и регистрации: библиотека, история и плейлисты хранятся локально.
