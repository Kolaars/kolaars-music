# Discord Rich Presence

Kolaars Music может показывать текущий трек в профиле Discord. Функция
необязательная, по умолчанию выключена и не отправляет данные никуда, кроме
локального клиента Discord на этом же компьютере.

## Что видно в Discord

- название трека;
- исполнитель и альбом;
- состояние «играет» / «пауза» и прошедшее время;
- обложка, если у трека есть публичный https-адрес обложки;
- кнопки, если у трека есть публичная ссылка.

Активность отправляется с типом `Listening`, поэтому Discord показывает её как
«Слушает Kolaars music», а не «Играет в». Название приложения («Kolaars music»)
задаётся в Developer Portal и от кода не зависит.

Discord должен быть запущен как настольное приложение для Windows. В браузерной
версии Discord Rich Presence не работает: у браузера нет доступа к локальному
RPC-сокету.

## Настройка

1. Откройте **Настройки → Discord Rich Presence**.
2. Включите переключатель «Показывать в Discord».

Официальный Application ID уже встроен в приложение, поэтому создавать своё
приложение Discord не нужно. Поле **Application ID** оставлено для форков и
отдельных сборок: его можно заменить на идентификатор собственного приложения из
[Discord Developer Portal](https://discord.com/developers/applications).

Application ID — публичный идентификатор приложения. Это **не** токен бота и не
секрет: он не даёт доступа к аккаунту и хранится в обычных настройках профиля.
Приложение проверяет, что ID состоит из 17–20 цифр, поэтому токен вставить не
получится.

Если Discord не запущен, приложение не падает и не показывает ошибку поверх
плеера: в настройках будет состояние «Нет подключения», а подключение повторится
автоматически, когда Discord появится.

## Обложка

Discord загружает картинку сам, по публичному https-адресу. Поэтому обложки
Internet Archive, YouTube и SoundCloud видны, а обложка локального файла — нет:
она лежит на диске или отдаётся по внутренней схеме `kmedia://`, которую Discord
не может открыть. Локальный путь не отправляется в Discord даже частично.

Если для локальных треков нужна картинка-заглушка, загрузите её как Rich
Presence asset в своём приложении Discord (Developer Portal → **Rich Presence →
Art Assets**) и используйте её ключ вместо URL. Официальное встроенное
приложение такой ассет не содержит.

## Кнопки

Discord Rich Presence поддерживает только кнопки-ссылки. Нажатие открывает URL в
браузере; запустить действие внутри Kolaars Music или скачать файл «силами»
приложения из Discord нельзя.

Поэтому кнопки зависят от источника трека:

| Трек | Кнопки |
| --- | --- |
| Internet Archive / встроенный открытый каталог | **Скачать** — прямой публичный файл, **Источник** — страница записи |
| YouTube Music | **Открыть в YouTube Music** — страница видео, **Скачать Kolaars Music** |
| SoundCloud | **Открыть в SoundCloud** — страница трека, **Скачать Kolaars Music** |
| Локальный файл | **Найти в YouTube Music** — публичный поиск, **Скачать Kolaars Music** |

У локального файла нет публичной страницы, поэтому кнопка ведёт не на сам трек,
а на поиск в YouTube Music. Это честнее, чем выдавать поиск за ссылку на запись.

Discord разрешает не больше двух кнопок. Когда у трека занят только один слот,
второй отдаётся ссылке на страницу релизов Kolaars Music — она открывается у
зрителя в браузере и ведёт на GitHub Releases. У записей Internet Archive оба
слота заняты самим треком, поэтому кнопки приложения там нет.

Прямая кнопка «Скачать» появляется только для открытых записей каталога, у
которых есть публичный файл. Для потоков YouTube и SoundCloud приложение не
создаёт ссылку на скачивание: звук идёт из официального плеера сервиса, а не из
файла, который можно сохранить.

Discord не показывает кнопки автору активности в его собственном профиле — это
ограничение клиента. Чтобы проверить кнопки, откройте профиль с другого аккаунта
или попросите друга посмотреть.

## Приватность

При включённой функции в Discord передаются только название, исполнитель, альбом,
состояние, публичный адрес обложки и публичные ссылки текущего трека. История
прослушивания, библиотека, профили и ключи API не передаются. Соединение идёт
через локальный IPC-сокет Discord, без собственных серверов и телеметрии.
