# Данные и лицензии

Kolaars Music не содержит собственной музыки: приложение воспроизводит записи с их
первоисточников и показывает пользователю ссылку и лицензию каждой записи. Здесь описано, что
именно лежит в репозитории, откуда это взято и как обновлять данные.

## Что лежит в репозитории

| Файл | Содержимое | Лицензия |
| --- | --- | --- |
| `data/seed-catalog.json` | 211 треков, 10 подборок — метаданные и прямые ссылки на Internet Archive | см. таблицу лицензий ниже |
| `data/lyrics-pack.json` | 65 песен общественного достояния, опубликованных до 1931 года | общественное достояние (США) |
| `resources/icon*.png`, `resources/icon.ico`, `resources/icons/*.png` | иконки приложения | MIT (генерируются скриптом) |
| `src/**`, `scripts/**` | исходный код | MIT |

Файлов аудио в репозитории нет и не будет: `streamUrl` указывает на `archive.org`, а обложки
подгружаются как обычные изображения.

## Музыка: `data/seed-catalog.json`

Каталог собирается из **публичных API Internet Archive** и полностью воспроизводим. Каждая
запись содержит:

```json
{
  "id": "arc:78_900-miles_woody-guthrie-cisco-houston-pete-seeger_gbia8000366",
  "title": "FOLKSAY",
  "artist": "…",
  "album": "American Folksay Ballads and Dances",
  "year": 1944,
  "genres": ["Blues", "78rpm"],
  "duration": 173.59,
  "artwork": "https://archive.org/services/img/<identifier>",
  "source": "seed",
  "streamUrl": "https://archive.org/download/<identifier>/<file>.mp3",
  "identifier": "78_900-miles_…",
  "license": "Общественное достояние",
  "licenseUrl": "https://archive.org/details/georgeblood",
  "sourceUrl": "https://archive.org/details/78_900-miles_…",
  "shelf": "blues"
}
```

Идентификаторы треков начинаются с `arc:`; это же значение используется как ключ разрешения
при онлайн-поиске.

### Коллекции

### Лицензии записей

| Лицензия | Треков |
| --- | --- |
| Общественное достояние | 188 |
| CC BY-NC-ND 3.0 / CC BY-NC-SA 3.0 / CC BY-NC 2.0 / CC BY-NC-SA 2.0 / CC BY-NC 3.0 / CC BY-NC-ND 2.0 / CC BY-NC-SA 4.0 | 23 |
| Creative Commons (общая формулировка из метаданных) | — |

Подавляющее большинство — общественное достояние. Оставшаяся часть — релизы независимых
лейблов под лицензиями Creative Commons, преимущественно с условиями **NonCommercial**
(некоммерческое использование) и **NoDerivatives/ShareAlike**. Это означает:

- Kolaars Music распространяется бесплатно и некоммерчески, поэтому воспроизведение этих
  записей допустимо;
- при повторном использовании записей в своих целях проверяйте условия конкретной лицензии —
  приложение показывает её для каждого трека и ссылается на первоисточник;
- приложение не модифицирует и не перекодирует записи: они воспроизводятся как есть, с
  серверов Internet Archive.

### Требования к кандидатам при сборке

Скрипт включает запись только если:

- `mediatype:audio` — это музыкальная запись, а не видео или текст;
- запись находится в одной из перечисленных открытых коллекций;
- удалось определить прямой URL аудиофайла и хотя бы одно поле метаданных (название,
  исполнитель);
- формат файла — MP3, Ogg Vorbis или FLAC (предпочтение отдаётся лучшему качеству).

Записи сортируются по числу загрузок: в подборку попадают самые популярные элементы, поэтому
свежая установка сразу выглядит наполненной.

## Тексты: `data/lyrics-pack.json`

Встроенный сборник — это тексты произведений, **опубликованных до 1931 года**: по закону об
авторском праве США они находятся в общественном достоянии, а в большинстве других юрисдикций
охрана также истекла по возрасту. Формат описан в [lyrics.md](lyrics.md).

Правила для новых песен:

1. автор умер или произведение опубликовано до 1931 года — обязательно проверьте;
2. указывайте `title`, автора текста в `artist`, год первой публикации в `year` и язык в
   `language`;
3. добавляйте `aliases` для альтернативных названий (они помогают сопоставлению с
   «грязными» названиями в Internet Archive);
4. текст — построчно в массиве `lyrics[]`, без аккордов, ремарок вроде «(x2)» и куплетов на
   другие языки, если они не часть оригинала.

Онлайн-тексты (LRCLIB, Wikisource) в репозиторий не складываются: они запрашиваются по
действию пользователя и остаются в его личной библиотеке.

## Обновление данных

### Каталог музыки

```powershell
node scripts/build-seed-catalog.mjs                     # 24 трека на подборку
node scripts/build-seed-catalog.mjs --per-shelf 40      # больше записей
node scripts/build-seed-catalog.mjs --out data/seed-catalog.json
```

Скрипт обращается к `archive.org/advancedsearch.php` и `archive.org/metadata/<id>`,
подставляет `User-Agent` проекта и повторяет запросы при сбоях. Ничего не скачивается.

Чтобы добавить новую подборку, впишите её в массив `SHELVES` внутри скрипта, а затем — в
`SHELVES` в `src/main/providers/archive.ts` (там же живут подписи и сортировка). Оба списка
должны совпадать по `id`.

### Иконки

```powershell
node scripts/generate-icons.mjs
```

Скрипт рисует иконки пиксельной математикой и сам кодирует PNG (zlib + CRC32 из стандартной
библиотеки Node), а затем упаковывает их в многоразмерный `.ico`. Дизайн-инструменты не нужны.

## Проверка данных

- `npm run smoke` проверяет, что обзорные подборки отрисовались из встроенного каталога и что
  живой поиск в Internet Archive возвращает строки.
- `node scripts/smoke.mjs --screenshot=docs/screenshots` сохраняет экраны, по которым видно,
  что каталог и тексты на месте.
- Любую запись можно открыть по `sourceUrl` и убедиться в первоисточнике и лицензии.
